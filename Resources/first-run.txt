Zephyr

To install

1.  Drag Zephyr onto the Applications folder in this window.
2.  Open it. macOS will refuse the first time, and say the developer
    cannot be verified.
3.  Open System Settings, go to Privacy & Security, scroll to the
    bottom, and click "Open Anyway".
4.  Open Zephyr again and confirm.

That is once. From then on it opens like anything else.

On macOS 14 and earlier, step 3 is shorter: right-click Zephyr in the
Applications folder, choose Open, and confirm.

Why this happens

Zephyr is free and open source. Apple charges 99 US dollars a year for
the certificate that makes this dialog go away, and it buys nothing
else — the application is the same either way. The source is at
github.com/n0ctal/Zephyr, and the build that made this disk image is
reproducible from it.

What it needs from the system

Zephyr reads the sensors without any privilege at all. Controlling the
fans needs a small helper running as root, and Zephyr does not install
that for you. Until it is installed, the readings work and the controls
do nothing.

To install it: open Zephyr's menu in the menu bar and choose "Install
helper…". A window gives you the exact command and a button that copies
it; paste it into Terminal and it asks for your password once. The
settings window carries the same offer in a banner across the top while
the helper is missing.

Nothing leaves the machine: there is no network code in the application
at all.
